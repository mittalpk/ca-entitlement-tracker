# BK1-US-018 — Gmail/Slack dispatch with separate urgent/breach channel

**Workflow ID:** BK1
**Phase:** 3 — Core Build (Alpha)
**Status:** NOT STARTED
**Story points:** M

---

**As a** Custody Client (end beneficiary),
**I want** to receive the drafted notification via Gmail or Slack, with urgent/breach notifications on a separate channel from informational/reminder ones,
**so that** time-critical voluntary-election notices are not lost in routine-notification volume.

**Traces to:** FR-021, FR-022 (`requirements.md` §4.6)

**Acceptance criteria:**
- Given a drafted notification and its escalation tier, When dispatched, Then it reaches the configured Gmail address or Slack channel for that tier.
- Given an URGENT or BREACH tier notification, When dispatched, Then it uses a distinct, configurable channel from INFORMATIONAL/REMINDER (AC-016).

**Definition of Ready:** LLM Chain node built (BK1-US-017); Gmail/Slack credentials configured per `SETUP.md`.

**Definition of Done:** Dispatch node built and manually verified for at least one tier per channel.

**Dependencies:** BK1-US-017
