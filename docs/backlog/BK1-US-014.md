# BK1-US-014 — Google Sheets lookup by positionAsOfRecordDate only

**Workflow ID:** BK1
**Phase:** 3 — Core Build (Alpha)
**Status:** NOT STARTED
**Story points:** S

---

**As a** Technology / Workflow Engineer,
**I want** the Google Sheets Lookup node to retrieve positions strictly by `positionAsOfRecordDate`, never a live position field, and to handle the no-match case without erroring,
**so that** entitlement is never computed against a settlement-in-transit or stale position (BR-003).

**Traces to:** FR-004, FR-005 (`requirements.md` §4.2)

**Acceptance criteria:**
- Given an ISIN with matching position rows, When looked up, Then only `positionAsOfRecordDate` is read as the authoritative holding field.
- Given an ISIN with no matching rows, When looked up, Then the workflow logs a zero-entitlement record and exits without error (AC-004).

**Definition of Ready:** Position-book mock Sheet provisioned per `03-data-contract.md` schema.

**Definition of Done:** Lookup node built with a sticky note documenting the record-date-only rule (per `requirements.md` §8.2 critical data integrity rule).

**Dependencies:** BK1-US-013
